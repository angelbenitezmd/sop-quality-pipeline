## Purpose

This procedure describes how the rotary vial filling machine (Asset EQP-FIL-01) should be set up, operated, and qualified so that fill volume, stopper seating, and machine integrity remain within validated limits, and it should be read together with the qualification lifecycle that is applied during installation qualification, operational qualification, and performance qualification so that every operator understands that the acceptance limits recorded during those studies are the same limits that govern routine production and that no deviation from them should be introduced without formal change control.

## Scope

This procedure applies to the operation of the vial filling machine located in the Grade A filling zone of Cleanroom A, including format changeover, fill-weight setup, and post-run shutdown, and it applies to all engineering technicians and qualified operators who are assigned to the line.

## Responsibilities

Qualified operators should perform setup and operation as written, engineering technicians should perform format changeover and mechanical adjustment, and the Engineering Manager should ensure that qualification status is current before the machine is released for use.

## Equipment and Materials

- Rotary filling machine EQP-FIL-01 with dosing pumps and peristaltic manifold
- Calibrated analytical balance for fill-weight checks
- Format parts for the vial size in the batch record
- Sterilized product-contact assembly released per SOP-MFG-001

## Procedure

Step 1: Confirm that the machine carries a current qualification label and that the calibration due dates for the balance and the load cells have not passed, because operation should not begin whenever any qualification or calibration status is expired, and the operator should record the equipment identification number in the batch record before any further step is started.

Step 2: Install the sterilized product-contact assembly, connect the dosing pumps, and verify that the format parts match the vial size specified in the batch record, and it should be confirmed that all guards are seated and that the interlocks respond correctly when tested.

Step 3: Prime the dosing system and set the target fill weight, then perform a series of fill-weight checks at the start of the run so that each dosing station is shown to deliver product within the tare-corrected acceptance window, and the operator should adjust any station that trends toward a limit before full-speed filling is authorized, since allowing a drifting station to continue is exactly the situation that the in-process weight checks are intended to prevent.

Step 4: Start filling at qualified line speed, monitor stopper seating and reject stations continuously, and record fill weights at the frequency defined in the batch record so that the data set required for performance qualification trending is captured contemporaneously.

Step 5: At the end of the run, stop the machine, purge and disconnect the product-contact assembly, and route it for cleaning, and the completed records should be reviewed against the good documentation practices that are defined in SOP-DOC-001.

## Qualification

Installation, operational, and performance qualification should be executed and maintained in accordance with the analytical instrument qualification expectations of USP <1058>, and the automated dosing and recipe-management software should be qualified using the risk-based, category-based approach described in GAMP 5 (2nd Ed, 2022). Requalification should be triggered by major maintenance, relocation, or any change assessed as significant under change control.
