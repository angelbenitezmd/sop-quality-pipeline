## 1. Purpose

This procedure defines the lifecycle of a standard operating procedure (SOP) at
Building 4. It exists so that every SOP is authored, reviewed, approved, and reviewed
again on a set cadence.

## 2. Scope

This procedure applies to all controlled SOPs across every department. It covers new
documents, revisions, periodic review, and retirement.

## 3. Responsibilities

Authors must draft each SOP in the house style. Subject-matter experts must review the
content for accuracy. Quality Systems must control the master library. The document
owner must complete periodic review on time.

## 4. House Style Standard

1. Use markdown headings in the form "## N. Title".
2. Write each procedure step as a verb-first imperative sentence.
3. Use the obligation word "must" for every requirement.
4. Keep sentences short and in the active voice.
5. Follow the documentation rules in SOP-DOC-001.

## 5. Authoring and Review

1. Draft the SOP against the approved template.
2. Route the draft to the named subject-matter experts.
3. Resolve every review comment before approval.
4. Obtain approval signatures from the owner and Quality Systems.
5. Assign the next version number on each change.

## 6. Effective Date and Training

1. Set an effective date that allows time for training.
2. Train all affected staff before the effective date.
3. Release the approved SOP into the controlled library.
4. Withdraw the superseded version on the same date.

## 7. Periodic Review

1. Review each SOP at least every two years.
2. Confirm that the content still matches current practice.
3. Record the outcome even when no change is needed.
4. Revise the SOP when the review finds a gap.
5. Manage each content change through SOP-DOC-003.

## 8. Retirement

1. Retire an SOP when the process no longer applies.
2. Record the reason for retirement.
3. Remove the retired SOP from active use.
4. Archive the record per the site retention schedule.
