## 1. Purpose

This procedure defines how to classify and recertify the cleanrooms of Building 4. It
exists so that each room meets its assigned air cleanliness grade at rest and in
operation.

## 2. Scope

This procedure applies to all classified rooms that support sterile fill-finish. It
covers Grade A, Grade B, Grade C, and Grade D areas.

## 3. Responsibilities

The EM Program Lead must schedule each recertification. Qualified technicians must run
the particle counts. Engineering must confirm airflow and pressure before testing.
Quality Assurance must approve every classification report.

## 4. Recertification Frequency

1. Recertify Grade A and Grade B areas at least every six months.
2. Recertify Grade C and Grade D areas at least every twelve months.
3. Recertify any area after a change that affects airflow or room integrity.
4. Record the due date for each room in the EM master schedule.

## 5. Classification Testing

1. Verify that the HVAC system has run in a stable state before testing.
2. Confirm room pressure cascade and air change rate against the design values.
3. Count airborne particles at 0.5 µm and 5.0 µm at each defined location.
4. Calculate the number of sample points from the room floor area.
5. Compare each result against the class limit for the assigned grade.

## 6. Acceptance Criteria

1. Accept the room only when every location meets its particle limit.
2. Apply the classification limits from ISO 14644-1:1999.
3. Test both the at-rest and the in-operation states.
4. Record any location that fails and place the room on hold.

## 7. Documentation

1. Issue a classification report for each recertification.
2. Attach the raw particle-count data to the report.
3. Route the report to Quality Assurance for approval.
4. File and control the approved report per SOP-DOC-001.
5. Feed the classified grades into the monitoring program under SOP-ENV-001.
