I. Purpose

This procedure defines how the laboratory incubates and reads biological indicators (BIs)
used to verify the effectiveness of steam sterilization cycles. A negative BI result
confirms that the cycle achieved the required lethality.

II. Scope

This procedure applies to self-contained BIs of *Geobacillus stearothermophilus* that are
processed in the autoclaves. BIs are exposed during autoclave cycles run under SOP-EQP-002
and then returned to the QC laboratory for incubation and readout.

III. Responsibilities

The QC analyst must incubate the BIs, read the results, and record the outcome. The QC
reviewer must confirm the record before the result is released. The QC Laboratory Manager
must ensure that the incubators are qualified and monitored.

IV. Materials and Equipment

- Self-contained BI ampoules of *Geobacillus stearothermophilus*
- A dedicated BI incubator set to 55–60 °C
- One unexposed BI from the same lot to serve as a positive control
- A calibrated timer and the BI logbook

V. Procedure

1. Confirm the lot number and expiry date of each BI before use.
2. Activate each exposed BI according to the manufacturer's instructions.
3. Set aside one unexposed BI from the same lot as a positive control and activate it the
   same way.
4. Place all BIs in the incubator at 55–60 °C.
5. Incubate for the full period stated by the manufacturer, which is 24 to 48 hours.
6. Read each BI by observing the color of the growth medium. Record any color change or
   turbidity.

VI. Acceptance Criteria

- Each exposed BI must show no growth (no color change and no turbidity).
- The positive control must show growth, which confirms the BIs are viable.
- If any exposed BI shows growth, the analyst must report the result and open an
  investigation. Affected loads are handled under the sterility program in SOP-QC-002.

VII. Documentation

Record the lot number, incubation start and end times, and the readout for every BI in the
BI logbook. Complete all entries following SOP-DOC-001, and have a second person review the
record before release.
